# PrefixQuery
PrefixQuery Source code and Supplementary Material.  

## Code

fasttree - the core code of our decoding attention kernel plugin.

pipeline - the core code of our pattern miner and data reorganizer, including pipeline strategy and reordering method.

lotus - relational interface, with llm operators supported.

note, you can install sglang with system command. Therefore, we do not provide the sglang source code.

## Proof

the proof material of NP-Hard difficulty of data reordering.  

## Dataset

Due to the large size of data, we do not provide the dataset. All dataset is available from Huggingface.
