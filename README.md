# PrefixQuery
PrefixQuery Source code and Supplementary Material.  

## Code

fasttree - the core code of our decoding attention kernel plugin.

pipeline - the core code of our pattern miner and data reorganizer, including pipeline strategy and reordering method. served as a background process.

lotus - relational interface provider, with LLMs operators supported.

## Proof

the proof material of NP-Hard difficulty of data reordering.  

## Dataset

Due to the large size of data, we do not provide the dataset. All dataset is available from Huggingface.
